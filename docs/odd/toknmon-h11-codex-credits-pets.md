# ToknMon — H11 Codex reset credits and Codex pets

Objective: the Codex page shows OpenAI's reset credits ("banked resets") next to the weekly dot grid, and Codex gets the eight ChatGPT pets as full-screen splash animations. Branch `feat/suite-h11-h13`, delivery strategy `feature-branch-chain` (one PR per milestone H11/H12/H13), runners: `daemon/.venv/bin/python -m pytest daemon/tests -q`, `node --test tools/test/`, `pio run -d firmware -e sim|waveshare_amoled_216`.

## Specs

- **S1** — User (2026-10-21, verbatim): "Los avatars de claude que tiene este proyecto me gustan (https://github.com/nathanjohnpayne/Petmeter) podemos integrarlos para codex, además de integrar lo de los banked resets de codex (claude creo que también tiene)".
  - **S1.1** Research (L2): Petmeter's Claude avatars are the official Anthropic Clawd GIFs we already ship; what it adds for Codex are eight ChatGPT "pets" (Bsod, Codex, Dewey, Fireball, Null Signal, Rocky, Seedy, Stacky) and the Codex **reset credits** (OpenAI-granted credits that clear an exhausted limit; each expires 30 days after grant). Claude has no equivalent (Petmeter's Claude collector only derives reset minutes; Anthropic's usage API exposes none) → documented, no Claude change.
  - **S1.2** Daemon, Codex provider: besides the local `rollout-*.jsonl` windows, fetch reset credits with the Codex CLI OAuth token from `~/.codex/auth.json` (`auth_mode: chatgpt`, `tokens.access_token`, `tokens.account_id`): `GET https://chatgpt.com/backend-api/wham/usage` (`rate_limit_reset_credits.available_count`), `GET …/wham/rate-limit-reset-credits` (`credits[]` with `status == "available"`, `expires_at`), `GET …/wham/rate-limit-reset-credits/history` or the history endpoint Petmeter uses (`events[].kind == "used"`, count in the trailing 30 days). Headers as in Petmeter's `daemon/collectors/codex.py` (read it from GitHub, copy the request shape, not the file). Cache 1 h; any HTTP/auth/parse failure logs once and omits the credit fields (the local usage still goes out). No token refresh (Codex CLI owns the token).
  - **S1.3** Payload: `rc` = credits held, `ru` = credits used in the trailing 30 days, `rm` = minutes until the soonest held credit expires (omitted when unknown). All three omitted when the fetch is unavailable. Documented in `docs/providers.md` payload table. Size budget: these keys are dropped after `m` and before `fl` when the payload exceeds the MTU.
  - **S1.4** Firmware, Codex page (dot grid layout, PSRAM boards): a "Resets" ledger under the grid header: `rc + ru` cells (lit = held in Codex accent, hollow = used), the number held as a big figure, and a line "Next expires in Xd" / "Xh" / "All used" / "Available" (expiry unknown). Hidden when the payload carries neither `rc` nor `ru`. Non-PSRAM boards (two-bar layout) show one text line "Resets: N held, M used". New fields in `data.h`, parsed in `main.cpp`, cleared with the slot.
  - **S1.5** Codex pets: `tools/convert_pet_spritesheet.py` (Pillow, `-I`) downsamples a 1536×1872 WebP sheet (8 columns × 9 rows of 192×208) into our grid text format `assets/animations/codex.pet-<name>.txt`, 16-colour palette, feet on row 36 of the 55×37 stage, one file per pet with the nine rows as acts (idle 6f, walking 8f, running 8f, waving 4f, jumping 5f, dizzy 8f, thinking 6f, laptop 6f, happy 6f; holds 330 ms for idle, 90 ms otherwise, as Petmeter). The sheets are downloaded by `tools/fetch_codex_pets.sh` from Petmeter's `research/codex-pets/` into `research/codex-pets/` (git-ignored, like `research/clawd-official/`), and the converted grids are committed. The pets join Codex's full-screen splash set (tap cycles them, `splash next|prev`); the Codex corner icon from H10 is unchanged. `NOTICE.md` gets an OpenAI entry mirroring the Anthropic one (user decision L3).
  - **S1.6** Flash budget: the 216 build stays under 85 % of the app partition; if the eight pets do not fit, keep the four smallest and record it.
