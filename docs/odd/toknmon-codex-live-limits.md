# ToknMon — Codex meter from live usage when local session logs are gone

Objective: the Codex meter shows the account's rate limits even when the Codex CLI has written no fresh, uncompressed session log, and the fix reaches every ToknMon user through GitHub. Branch `fix/codex-live-limits` from `main` `5d1f298`; delivery: one PR (forecast ≈ 300 authored lines); runner `daemon/.venv/bin/python -m pytest daemon/tests -q`.

## Specs

- **S1** — The Codex meter comes back (L1: "revisa que pasa con mi device, no muestra el medidor de codex"). With a ChatGPT sign-in in `${CODEX_HOME:-~/.codex}/auth.json`, the Codex provider reads the rate-limit windows from `GET https://chatgpt.com/backend-api/wham/usage` (`rate_limit.primary_window` / `secondary_window`: `used_percent`, `limit_window_seconds`, `reset_at` or `reset_after_seconds`), cached 5 minutes, and maps them with the same rules as the rollout snapshot (window ≤ 10 h → `5h` bar, longer → `Weekly`; a window the plan does not report is omitted). It no longer needs a `rollout-*.jsonl` from the last 7 days.
- **S2** — Local logs stay the fallback. Without a ChatGPT sign-in (API-key login, no `auth.json`), or when the request fails (network, expired token, unexpected body), the provider uses the newest `rate_limits` entry from the uncompressed rollout logs as before; with neither it reports no data as before. When both exist, the newer one wins (a turn written after the last fetch shows at once). Failures are logged once, never with the token.
- **S3** — `codex_credits = off` keeps its documented promise ("off = never call the network; the Codex slot shows local usage only"): no request at all, local logs only. Reset credits (`rc`/`ru`/`rm`) keep their hourly cadence and their payload keys.
- **S4** — Detection (`providers = auto`) also counts the compressed `rollout-*.jsonl.zst` logs that current Codex releases leave behind, so an install whose sessions are all compressed is still detected.
- **S5** — Publish for every user (L2: "Si hay que arreglarlo para que funcione y poder publicarlo en github para todas las personas que utilizan nuestro meter"): docs (README, `docs/providers.md`, `docs/install-macos.md`, `docs/troubleshooting.md`, `daemon/config.example`), CHANGELOG `[Unreleased]`, install on the user's Mac and check the board, push, PR on `edgarbaldemarmx/toknmon`, CI, merge.
