# The ToknMon menu-bar app (macOS)

`ToknMon.app` is a small menu-bar app that shows what the daemon last sent to
the board and edits the daemon's configuration without a terminal. It never
talks to the board itself: the daemon keeps owning Bluetooth, and the app only
reads `~/.config/toknmon/status.json` and rewrites keys in
`~/.config/toknmon/config`, which the daemon re-reads on its next poll.

The installer builds and starts it (`[7/7] Menu-bar app`); `--no-gui` skips
it. It lives in `~/Applications/ToknMon.app` and is started at login by the
`com.toknmon.menubar` launch agent.

## The menu

| Item | What it does |
| --- | --- |
| One line per provider, e.g. `Claude · 5h 32% · week 61%`, `Codex · week 37% · resets 2 held` | the last values the daemon sent for that provider; `no data` when the last poll failed; providers absent from `status.json` are not listed. Refreshed every 10 s. |
| `Device: <name> · connected / offline` | the board's Bluetooth name from the config and whether the daemon currently holds the BLE link |
| `Device name…` | a dialog to rename the board (1–18 printable ASCII characters, no `#`). The daemon pushes the new name to the board on its next poll; the board stores it and restarts its advertising, so re-pairing is not needed. |
| `Apps ▸ Meter / Focus` | which apps the board offers. Meter is always on; unchecking Focus hides the Focus timer and the app center (config key `apps`). |
| `Providers ▸ Auto / Claude / Codex / Kimi / Grok` | `Auto` polls every provider whose CLI is installed and logged in; checking individual providers pins an explicit list (config key `providers`). |
| `Sound ▸ Chime / Beep` | the session-reset chime and the attention beep on the board (`chime`, `beep`) |
| `Clock ▸ Off / Auto / 12h / 24h` | the clock in the board's title (`clock`) |
| `Restart daemon` | `launchctl kickstart -k gui/$UID/com.toknmon.daemon` |
| `Open config file` / `Open logs` | open `~/.config/toknmon/config` in your editor / `~/Library/Logs/toknmon.err.log` |
| `About ToknMon` / `Quit` | version from `daemon/VERSION`; Quit stops the app until the next login (the daemon keeps running) |

Every edit goes through `daemon/gui/config_store.py`, which rewrites the
affected `key = value` line in place and keeps comments and other keys.

## Running it from the clone

```bash
daemon/.venv/bin/python -m pip install -r daemon/requirements-gui.txt   # rumps, py2app (the installer does this)
cd daemon && .venv/bin/python -m gui.menubar                             # run without building the .app
bash tools/build_mac_app.sh                                              # -> /tmp/toknmon-app-build/dist/ToknMon.app and a DMG
OUT=/path/outside/the/repo bash tools/build_mac_app.sh                   # pick the build dir
```

The build is ad-hoc signed (`codesign --sign -`), so a copy downloaded from
elsewhere needs **Open Anyway** in *System Settings → Privacy & Security* the
first time; the installer's local build does not, because the app was built
on this Mac.

## Files

| Path | Role |
| --- | --- |
| `daemon/gui/menubar.py` | the rumps app (menu wiring only) |
| `daemon/gui/model.py` | pure formatting/state helpers, unit-tested in `daemon/tests/test_gui_model.py` |
| `daemon/gui/config_store.py` | in-place config editor, tested in `daemon/tests/test_gui_config_store.py` |
| `daemon/gui/setup_app.py`, `daemon/gui/ToknMon.py` | py2app entry and bundle metadata (`LSUIElement`, `com.toknmon.menubar`) |
| `daemon/gui/assets/toknmon-menubar*.png` | template (monochrome) status-bar icon, generated by `daemon/gui/make_icon.py` |
| `daemon/com.toknmon.menubar.plist` | launch-agent template rendered by the installer |
| `~/.config/toknmon/status.json` | written by the daemon after every poll: timestamp, link state, device name, apps, per-provider last payload |

## Troubleshooting

| Symptom | What to check |
| --- | --- |
| No icon in the menu bar | `launchctl list \| grep toknmon.menubar`; `tail ~/Library/Logs/toknmon-menubar.log`; `open ~/Applications/ToknMon.app` |
| Lines say `no data` | the daemon is not running or its last poll failed: `tail -F ~/Library/Logs/toknmon.err.log` |
| `Device: … · offline` | the board is off, asleep, or not paired; the daemon logs `Scanning…` until it finds it |
| An edit does not reach the board | the daemon re-reads the config on its next poll (about a minute); `apps` and the device name are pushed only when they change (`~/.config/toknmon/state.json` holds the last pushed values) |
